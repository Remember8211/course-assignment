# 课程作业

工业人工智能课程的DQN栅格导航实验，配套论文《基于自中心感知与深度Q网络的移动机器人栅格导航方法研究》。

`agv_dqn/`包含实验代码、训练后的模型、地图、训练日志和评估结果。安装、评估和训练命令见[实验说明](agv_dqn/README.md)。文件校验值记录于[MANIFEST.sha256](MANIFEST.sha256)。

在固定10×10地图、固定起终点的实验中，保存模型的路径为18次有效移动，与A*最短路径一致。在指定的十张未见地图中完成8张。动态评估各30回合，静态训练对照与动态训练模型均全部到达，平均有效移动次数分别为26.7和18.4。

这些数字对应随仓库保存的单种子模型及指定测试任务。环境会阻止机器人进入障碍格，移动障碍也不会进入机器人当前所在格；到达率应结合受阻动作次数解读。动态对照的训练预算不同，结果不能单独证明运动预测能力。感知消融尚未完成。
