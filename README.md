# 课程作业

工业人工智能课程的强化学习实验，包含DQN移动机器人栅格导航和SAC平面三连杆机械臂到达控制。

| 实验 | 内容入口 | 当前证据 |
|---|---|---|
| DQN栅格导航 | [代码、模型与复现说明](agv_dqn/README.md) | 固定地图路径18次有效移动，与A*最短路径一致；指定十张未见地图完成8张。动态对照各30回合均到达，平均有效移动次数26.7与18.4。 |
| SAC机械臂 | [三个阶段的代码与资料](arm_rl/README.md) | 原随机评估、固定配对验证及单种子修订训练诊断完整保留；原到达标记不等同于安全成功率，配对受阻测试未获得原SAC安全成功案例。 |

DQN结果对应单种子模型及指定任务。环境会阻止机器人进入障碍格，移动障碍也不会进入机器人当前所在格；到达率需结合受阻动作次数解读。动态对照训练预算不同，不单独证明运动预测能力，感知消融尚未完成。

SAC保留原实验的指标限制、成功与失败记录。修订训练仅种子0完成30万步，种子1、2及独立测试尚未完成，不将其描述为已完成的三种子研究。具体统计口径和已知问题见各阶段说明。

文件校验值见[MANIFEST.sha256](MANIFEST.sha256)。论文正文、期刊模板、虚拟环境和临时复现输出不在本仓库中。本次新增SAC资料不重新训练或执行策略，也不改变既有DQN代码、模型与结果。
